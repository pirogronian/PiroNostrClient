Welcome to PiroNostrClient v1.0, oriented mainly on wiki support, but intended to evolve.

Project code repository

Current state: Alpha

What works:

  • Searching articles (by id, author, time, custom tags)
  • Viewing articles content (plain/djot/asciidoc), metadata and raw event
  • Editing and publishing articles
  • Saving to/restoring from draft
  • Handling legacy wikilinks
  • Login with NIP-07, NIP-46, private key & NIP-49
  • Managing relays
  • Settings publishing/synchronization
What is planned:
  • Better editor for supported formats.
  • Managing WOT (Web Of Trust)
