Welcome to PiroNostrClient, oriented mainly on wiki support, but intended to evolve.

Project code repository

Current state: Alpha

What works:

  • Searching articles (by id, author, time, custom tags)
  • Viewing articles content (plain/djot/asciidoc), metadata and raw event
  • Login with NIP-07
  • Showing connected relays
What is planned:
  • Editing and publishing articles
  • Saving to/restoring from draft
  • Handling legacy wikilinks
  • Managing relays
  • Managing WOT (Web Of Trust)
  • Login with private key, NIP-49, NIP-46
